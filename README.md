# mathai-2026.github.io

Website for the 6th MATH-AI Workshop at NeurIPS 2026.

## Where things live

- `_config.yml`: site title, venue line, navbar links, and the title/subtitle shared by all top-level pages
- `*.md` at the root: one file per page (`index`, `cfp`, `speakers`, `organizers`, `papers`, `schedule`)
- `_includes/key_dates.md`: key dates, shown on both the home page and the call for papers
- `_data/speakers.yml`, `_data/organizers.yml`: people shown on the site (photos in `img/`)
- `_data/accepted_papers.yml`, `_data/reviewer_acknowledgements.yml`: generated by `_scripts/export_openreview.py` (see `_scripts/README.md`)
